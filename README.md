# Foodie – Food Delivery Website

A basic food delivery frontend built with React, HTML, and CSS using Vite.

## Features
- Home section and navigation
- Food menu with Pizza, Burger, and Biryani
- Food prices and Order buttons (frontend demo only)
- Responsive basic layout

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite (usually http://localhost:5173/).

## Tech stack
- React
- JavaScript
- HTML
- CSS
- Vite

> This is a frontend learning project. Order buttons do not place real orders; no backend or payment processing is included.
