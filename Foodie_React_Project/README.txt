FOODIE - BASIC REACT FOOD DELIVERY PROJECT

STEP 1: Extract the ZIP file.
STEP 2: Open the extracted Foodie_React_Project folder in VS Code.
STEP 3: Open Terminal > New Terminal.
STEP 4: Run: npm install
STEP 5: Run: npm run dev
STEP 6: Open the localhost address shown in the terminal (usually http://localhost:5173).

FILES:
- index.html: Main HTML page
- src/App.jsx: React component and food menu
- src/main.jsx: React entry point
- src/style.css: CSS design
- package.json: Project dependencies and commands

NOTE:
This is a basic frontend demonstration. The Order buttons are visual only.
Internet connection is required for npm install.
